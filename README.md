# king-of-flow

Генератор фоновой музыки для сосредоточения и браузерный плеер «Поток». Звук синтезируется на месте: шум, дроны, атмосферные пады и джазовые прогрессии с амплитудной модуляцией.

## Плеер

Откройте `index.html` в браузере (или раздайте папку любым статическим сервером). Треки играются через Web Audio, файлы скачивать не нужно.

## Генератор

```bash
uv sync
uv run focusgen --help
uv run python library.py generate --count 2 --minutes 2
```

`library.py generate` пишет свои треки в `library/`. `library.py process` прогоняет через модулятор папку со своей или CC-музыкой; без строки в `credits.csv` результат кладётся в `personal/` и в публикацию не идёт.
