# king-of-flow

Генератор фоновой музыки для сосредоточения и браузерный плеер «Поток». Звук синтезируется на месте: шум, дроны, атмосферные пады и джазовые прогрессии с амплитудной модуляцией.

## Плеер

Откройте `index.html` в браузере (или раздайте папку любым статическим сервером). Треки играются через Web Audio, файлы скачивать не нужно.

## Генератор

```bash
uv sync
uv run focusgen --help
uv run python library.py generate --count 2 --minutes 2
```

`library.py generate` пишет свои треки в `library/`. `library.py process` прогоняет через модулятор папку со своей или CC-музыкой; без строки в `credits.csv` результат кладётся в `personal/` и в публикацию не идёт.

## Своя песня → инструментальная петля

`songloop.py` — локальный экспериментальный конвейер. По умолчанию запускает
Demucs `htdemucs` для выделения минуса, затем ранжирует участки 16–48 секунд
по сходству спектра на границах, перепадам громкости и тренду энергии.
Выдаёт до трёх WAV и `analysis.json` с временными границами и оценками.
Это эвристика, не распознавание музыкальных фраз или гарантия отсутствия вокала:
варианты нужно прослушать несколько раз подряд. В неудачной песне хорошей петли
может не оказаться. При найденном ритме границы привязаны к долям, длина — к блокам по четыре
предполагаемых такта. Размер 4/4 по умолчанию, для 3/4 задайте `--meter 3`.
Сильная доля и размер автоматически не распознаются. Без выраженного ритма
используется свободный поиск с предупреждением в отчёте.

Нужны ffmpeg, NumPy, SciPy и librosa; для удаления вокала дополнительно Demucs
(рекомендуется отдельное окружение Python 3.11 с совместимыми torch/torchaudio).
Первый запуск Demucs скачивает веса модели. Исходная песня обрабатывается локально.

```bash
python -m pip install numpy scipy librosa demucs
python songloop.py song.mp3 --out personal/loops
# Если минус уже есть, достаточно существующего окружения проекта:
uv run python songloop.py instrumental.wav --instrumental
```

Откройте полученный `loop-1.wav` в плеере и выберите «Готовая петля»:
этот режим сохраняет файл целиком и исходный темп. Старая обработка в браузере
вокал не удаляет. Результаты сохраняются в новой папке при каждом запуске.

Источники метода:
- https://github.com/facebookresearch/demucs — выделение источников; исходный репозиторий архивирован.
- https://dafx2020.mdw.ac.at/proceedings/papers/DAFx20in21_paper_41.pdf — Graph-Based Audio Looping and Granulation (2021).
Наш скрипт использует упрощённое ранжирование переходов, не полную реализацию статьи.

`collection.js` добавляет 24 синтезируемые аранжировки: пианино, нейлоновую гитару,
маримбу, электропиано, пэды, колокола и арпеджио. Это процедурная музыка,
а не новые студийные записи.

### Отбор фрагментов без слов и сравнение

`--instrumental-only` отбрасывает участки, где оценённая вокальная активность
занимает более 5% времени (порог энергии голоса относительно минуса −18 dB).
Это оценка активности выделенного стема, а не гарантия отсутствия слов.
При отдельном готовом минусе можно передать синхронный стем `--vocals vocals.wav`.
Для использования Demucs из другого окружения: `--demucs-python /path/to/python`.

В каждой папке результата есть `index.html` с плеерами тройного повтора,
`preview-N.wav` для проверки стыка и `loop-N.wav` для загрузки в «Поток».
Оценки и предупреждения доступны в `analysis.json`. Выход: stereo float WAV,
22 050 Гц. Автоматический монтаж разных фраз пока не реализован.

Beat tracker: https://librosa.org/doc/latest/generated/librosa.beat.beat_track.html

Проверки: `uv run python -m unittest discover -s tests -v`.

Для воспроизводимого CPU-окружения разделения (Python 3.11):

```bash
uv venv --python 3.11 .venv-separation
uv pip install --python .venv-separation/bin/python 'torch==2.5.1+cpu' 'torchaudio==2.5.1+cpu' --index-url https://download.pytorch.org/whl/cpu
uv pip install --python .venv-separation/bin/python 'demucs==4.1.0' 'numpy<2'
uv run python songloop.py song.mp3 --demucs-python .venv-separation/bin/python
```

Проверено локально: Demucs 4.1.0 + CPU PyTorch 2.5.1 на 24-секундном
инструментальном демо; чтение обоих стемов и создание петель/страницы сравнения.
Это техническая проверка, не оценка качества удаления вокала на песнях.

## Загрузить песню через интерфейс

Запустите `.venv/bin/python server.py` и откройте
http://127.0.0.1:8877/?upload. Выберите песню в блоке загрузки: сервер локально
удалит вокал и покажет до трёх петель с кнопками воспроизведения и скачивания.
Файлы сохраняются в `personal/web/`. Лимиты: 100 МБ, 16 секунд–15 минут,
одна обработка одновременно. Закрытие вкладки не отменяет начатую обработку.
Сервер слушает только 127.0.0.1; исходная песня не отправляется в облако.
`POTOK_DEMUCS_PYTHON` задаёт путь к Python с Demucs, `POTOK_PORT` — порт.
Для первого запуска нужны установленные зависимости и скачиваемые веса модели.
